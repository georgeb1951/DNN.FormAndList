BCC Forms 01.00.00

First release of BCC Forms, a standalone module derived from DNN Form and List 06.05.09 (MIT, DNN Community).

  • Requires DNN Platform 10.3.3 or later and .NET Framework 4.8.
  • Installs as its own module (BCCForms, folder DesktopModules/BCCForms) with its own tables (BCCForms_*); runs side by side with Form and List.
  • Single consolidated install script replaces the 22 historical Form and List upgrade scripts.
  • Security: the thumbnail handler now enforces folder view permissions, limits image types to jpg/png/gif/bmp, and caps width/height at 2000 px.
  • Security: reCAPTCHA tokens are verified with a POST request (secret no longer in the query string), with a 10-second timeout.
  • Removed the use of DotNetNuke.Services.SystemDateTime, which no longer exists in DNN 10.
