BCC Forms 01.02.00

  • Server-side paging: with paging on, and no list filter or search active, the list reads, sorts and pages in SQL and renders only the rows on screen, instead of loading every record. Sorting by text, number, date and yes/no fields happens in the database; other cases (filters, search, calculated fields, sorting by links or user names) keep the in-memory path, which is now linear too (late pages of big lists were slow).
  • List layouts: Table (sortable; on phones each record stacks as "title value" lines), Cards (a responsive grid of cards) and HTML template (your own header, item and footer HTML with [Field], [Field:Text], [UDT:EditLink], [UDT:TotalRecords] and other tokens, with a "Generate starter template" button). XSL stylesheets still work as before.
  • Fixed: lists set to an XSL stylesheet showed the plain table after the 01.01.00 setting rename.

BCC Forms 01.01.00

  • Display: forms, lists and settings screens follow DNN's form layout and the site theme's colours; responsive on small screens; date picker restyled to match the theme.
  • DNN 10: no obsolete DNN APIs are used any more (dependency injection throughout).
  • Security: user-entered HTML is cleaned by an allowlist sanitizer (the HtmlSanitizer library that ships with DNN 10) in place of the obsolete NoScripting filter. Scripts, event handlers, form controls and page-level tags are removed; plain-text fields round-trip unchanged.
  • Spam protection for anonymous users: one setting with None, DNN image CAPTCHA, Google reCAPTCHA v2, Google reCAPTCHA v3 (invisible, with a minimum score) or Cloudflare Turnstile. Submit stays blocked until the check passes, each form on a page gets its own widget, and every token is verified on the server (fail closed). Existing CAPTCHA settings carry over.
  • Spam protection: optional honeypot field (on by default) that bots fill in and people never see.
  • Security: list, XSL and token output now sanitize text and rich-text values that contain markup (covers imported and older data); the stored value is unchanged and still used for editing and CSV export. URL fields no longer render javascript:/data: links, and URL, file and e-mail captions are HTML-encoded.
  • XSL template generator rebuilt without layout tables; works on small screens.
  • Configuration field list: the Required / Display / Restricted / Searchable marks are drawn in the row's text colour, so they stay visible on any theme's alternating rows (DNN's grey tick icons vanished on grey rows); screen readers now hear the right Yes / No for each column.
  • Configuration and field editor: Save and Cancel no longer show twice (DNN's CommandButton drew a broken icon button next to the link); Cancel no longer triggers validation.
  • Form templates: "Generate template" now writes DNN form rows that line up in any theme (the old one assumed a Bootstrap 3 grid). Labels without help text now use DNN's own label markup, so every label in a form lines up, in the standard form and in templates. The generated template includes every field the form shows (it used to skip fields not displayed on the list) and the DNN CAPTCHA when that is selected. Template forms now hide restricted fields from users who may not edit them, as the standard form does, and always show the DNN CAPTCHA when it is on, even if the template has no place for it.
  • Module settings use their own BCCF_ names. The upgrade renames existing settings, and templates or exports made with the old names still import.
  • Internal Form and List names removed from code, CSS hooks and resources.

BCC Forms 01.00.00

First release of BCC Forms, a standalone module derived from DNN Form and List 06.05.09 (MIT, DNN Community).

  • Requires DNN Platform 10.3.3 or later and .NET Framework 4.8.
  • Installs as its own module (BCCForms, folder DesktopModules/BCCForms) with its own tables (BCCForms_*); runs side by side with Form and List.
  • Single consolidated install script replaces the 22 historical Form and List upgrade scripts.
  • Security: the thumbnail handler now enforces folder view permissions, limits image types to jpg/png/gif/bmp, and caps width/height at 2000 px.
  • Security: reCAPTCHA tokens are verified with a POST request (secret no longer in the query string), with a 10-second timeout.
  • Removed the use of DotNetNuke.Services.SystemDateTime, which no longer exists in DNN 10.
